# 《聪明的投资者》理科生导读地图

> 用途：① 自读原书时的导航 ② 喂给 OpenMAIC 做课程的结构化底稿
> 版本基准：人民邮电出版社译文（第 4 版，Jason Zweig 点评版）

## 0. 全书骨架（先建立地图）

格雷厄姆全书的论证链只有三块：

```
市场先生（第8章） → 你是谁（第1/4/5章：防御型 vs 进取型）
                      ↓
              安全边际（第20章）→ 一切决策的最终依据
```

其余章节都是这三块的展开：债券/基金是防御型工具箱，第 11/15/19 章是进取型的选股方法论，第 6/7 章是宏观判断，Zweig 点评负责把 1970 年代翻译到现在。

## 2. 五个必须内化的概念（课程核心单元）

1. **市场先生（Mr. Market）**：市场是躁郁症报价员。理科生理解方式：价格 = 价值 + 噪声项，且噪声项自相关（趋势）+ 均值回归。你的对手盘框架里的"情绪温度计"正是噪声项的观测器。
2. **安全边际**：所有估值的误差不可避免 → 唯一理性应对是打折买。注意格雷厄姆的算法（净流动资产打折）在 A 股几乎筛不出票，需现代化为 PE/PB 历史分位 + 股息率保护。
3. **防御型 vs 进取型**：选择依据是"你愿意投入多少研究时间"，不是"你想要多高收益"。诚实自评。
4. **投资 vs 投机**：定义是操作性的（三要件），不是资产类别。买茅台可以是投机，买垃圾股可以是投资——取决于分析深度和买入理由。
5. ** dolar-averaging（定期定额）+ 再平衡**：唯一不依赖预测的仓位管理法。

## 3. 已过时需修正的内容（理科生批判性阅读区）

| 书中观点 | 问题 | 现代修正 |
|---|---|---|
| 烟蒂股/净流动资产策略 | A 股无此标的，美股也消失 | → 低估值指数/红利策略承接其精神 |
| 债券=安全资产 | 1970s 高通胀已证伪，且 A 股债基有波动 | → "股债平衡"里债券理解为低波动资产即可 |
| 进取型散户自己选股 | 现代市场有效性远超 1970s | → 巴菲特修正案：普通人直接指数化 |
| 对成长股几乎全盘否定 | 略矫枉过正 | → 用安全边际思维买成长（GARP）是可接受折中 |

## 4. 学习路径（喂给 OpenMAIC 的课程结构建议）

1. **模块一：心智地基**（S 级章 8 + 概念 1/4）→ 目标：能解释"波动≠风险"
2. **模块二：自我定位**（章 1/4/5 + 概念 3）→ 目标：诚实写出自己是哪型
3. **模块三：安全边际实战**（章 20/14 + 概念 2，接 A 股数据实操）→ 目标：用 a-stock-data 拉真实数据给一只票算安全边际
4. **模块四：批判与修正**（第 3 节全部 + Zweig 点评精选）→ 目标：能说出格雷厄姆哪三条在 A 股失效
5. **结业检验**：回到 pi 苏格拉底对话，回答 5 道真票真题

## 5. 阅读纪律

- 每章读完 → 立刻来对话检验，间隔不超过 1 天
- 全程配一本 A 股自选股清单，每学一个概念就在真票上用一次
- Zweig 点评与原文冲突时，记下来带来讨论——那些冲突点恰是 50 年进化所在
